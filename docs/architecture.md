# Architecture status

Postmote is a Bun application with a loopback HTTP daemon and a separate stdio MCP mode. `src/main.ts` owns CLI dispatch, owner HTTP endpoints and the embedded dashboard. The stdio mode accesses the same SQLite data store directly rather than forwarding to the daemon. `src/db.ts` manages the schema; `src/vault.ts` encrypts stored credentials and draft bodies with a local key file. `src/thunderbird.ts` reads profile settings; `src/thunderbird-credentials.ts` imports password credentials from NSS when the owner requests it. The mail adapters use ImapFlow and Nodemailer with verified TLS.

MCP currently provides account listing, status, folders, recent message headers, paged IMAP search, raw and parsed message retrieval, bounded attachment chunks, revisioned plain-text drafts, reply and forward preparation, flags and guarded moves, INBOX polling, approval-based send requests, direct mail from a dedicated agent inbox to the owner-configured address, and delivery status. Scoped resources and basic prompts are available. HTML output, large attachments, forwarding attachments and portions of the planned contracts are not implemented. The approval flow and release acceptance tests need further work before production use. See `IMPLEMENTATION_STATUS.md`.
